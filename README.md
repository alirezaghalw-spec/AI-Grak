# هوش پرو (Hoosh Pro)

دستیار هوش مصنوعی شخصی، چندمنظوره و متن‌باز با اتصال به **OpenRouter** (دسترسی همزمان به ده‌ها مدل رایگان مانند Gemini, DeepSeek, Llama و...).

## 🌟 ویژگی‌های کلیدی

- **چند مدلی:** انتخاب بین مدل‌های مختلف رایگان و فوق‌العاده ارزان.
- **رابط کاربری مدرن:** طراحی اختصاصی، راست‌به‌چپ و حالت شب (Dark Mode).
- **پشتیبانی از فایل:** ارسال تصویر (Vision)، خواندن فایل‌های PDF و متنی.
- **اجرای کد پایتون:** امکان اجرای کدهای تولید شده توسط هوش مصنوعی و نمایش نمودار به صورت مستقیم.
- **تولید تصویر:** تولید تصویر از طریق پرامپت (با استفاده از Pollinations).
- **مکالمه صوتی:** تبدیل گفتار به نوشتار (STT) و خواندن پاسخ‌ها (TTS) به زبان فارسی.
- **فروشگاه ابزارها:** امکان نصب ابزارهای واقعی مثل جستجوی وب زنده و محیط اجرای کد.
- **ذخیره‌سازی محلی:** تاریخچه گفتگوها در مرورگر شما (بدون نیاز به دیتابیس) ذخیره می‌شود.

## 🚀 راهنمای نصب روی Render

1. مخزن (Repository) خود را به Render وصل کنید (New → Web Service).
2. تنظیمات زیر را وارد کنید:
   - **Runtime**: Python 3
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `uvicorn main:app --host 0.0.0.0 --port $PORT`
3. (اختیاری) در بخش Environment Variables، متغیری به نام `OPENROUTER_API_KEY` بسازید و کلید خود را وارد کنید. *(البته نیازی به این کار نیست و می‌توانید کلید را مستقیماً در تنظیمات سایت وارد کنید)*.
4. Deploy کنید.

## 🔑 نحوه استفاده

1. سایت را باز کنید.
2. روی دکمه **⚙ (تنظیمات)** کلیک کنید.
3. کلید API خود را (که از سایت [OpenRouter](https://openrouter.ai/keys) دریافت کرده‌اید و با `sk-or-v1-` شروع می‌شود) وارد کنید و ذخیره کنید.
4. از منوی **MODEL** یک مدل رایگان انتخاب کنید و شروع به گفتگو کنید!
