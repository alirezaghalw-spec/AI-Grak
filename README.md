# Hoosh-Grok

چت‌بات شخصی با مدل‌های Grok (xAI)

## ویژگی‌ها

- اتصال مستقیم به API گراک (xAI)
- رابط کاربری فارسی و راست‌به‌چپ
- قابلیت اجرای کد پایتون (Sandbox)
- استریم پاسخ‌ها
- پشتیبانی از چند گفتگو

## متغیرهای محیطی (Environment Variables)

در Render این دو متغیر را حتماً تنظیم کنید:

| نام متغیر       | توضیح                                      | مثال                          |
|-----------------|---------------------------------------------|-------------------------------|
| `XAI_API_KEY`   | کلید API از کنسول xAI                       | `xai-...`                     |
| `HOST_API_KEY`  | رمز ورود به سایت (حداقل ۱۶ کاراکتر)         | یک رشته تصادفی بلند           |

## اجرا روی Render

1. این مخزن را به Render وصل کنید (New → Web Service)
2. تنظیمات:
   - **Runtime**: Python 3
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `uvicorn main:app --host 0.0.0.0 --port $PORT`
3. دو Environment Variable بالا را اضافه کنید
4. Deploy کنید

بعد از دیپلوی، آدرس سایت را باز کنید و از بخش تنظیمات (⚙) رمز `HOST_API_KEY` را وارد کنید.
