# هوش پرو (Hoosh Pro)

دستیار هوش مصنوعی شخصی و چندمنظوره با اتصال به **OpenRouter** (دسترسی به ده‌ها مدل رایگان و ارزان). مجوز: MIT.

## 🌟 ویژگی‌ها

- **چند مدلی:** فهرست مدل‌ها زنده از OpenRouter گرفته می‌شود، جستجو دارد و مدل‌های منقضی خودکار حذف می‌شوند. اگر مدلی در دسترس نباشد، به مسیریاب رایگان برمی‌گردد.
- **مقایسهٔ دو مدل (⚔️):** پاسخ دو مدل کنار هم با برچسب نام مدل؛ هر دو در تاریخچه ذخیره می‌شوند و بعد از بارگذاری دوبارهٔ گفتگو هم دیده می‌شوند. فقط پاسخ مدل اول به‌عنوان بخشی از مکالمه به مدل‌ها فرستاده می‌شود.
- **رابط مدرن:** راست‌به‌چپ، حالت شب، منوی جمع‌وجور، قابل نصب به‌صورت PWA.
- **پیوست:** تصویر (فشرده‌سازی خودکار، فقط با آخرین پیام ارسال می‌شود)، PDF و فایل‌های متنی.
- **حالت عامل (🤖):** مدل می‌تواند صفحات وب را بخواند (و در صورت فعال بودن، کد پایتون اجرا کند) و با نتیجه ادامه دهد (حداکثر ۴ مرحله).
- **تولید تصویر:** با Pollinations (پرامپت انگلیسی، لینک خودکار اصلاح می‌شود).
- **مکالمه صوتی:** تبدیل گفتار به نوشتار و خواندن پاسخ‌ها. فارسی به صدای نصب‌شده روی دستگاه بستگی دارد.
- **نمودار mermaid** و هایلایت کد، دکمهٔ کپی و پیش‌نمایش HTML.
- **داشبورد هزینه (📊):** هزینه و توکن کل، نمودار ۷ روز اخیر و تفکیک بر اساس مدل (ذخیره در مرورگر شما).
- **آفلاین:** بعد از اولین بارگذاری موفق، برنامه و کتابخانه‌هایش کش می‌شوند و گفتگوهای قبلی بدون اینترنت قابل مشاهده‌اند (ارسال پیام نیاز به اینترنت دارد).
- **ذخیره محلی:** تاریخچه فقط در مرورگر شما نگه داشته می‌شود.

## 🚀 نصب روی Render

1. مخزن را به Render وصل کنید (New → Web Service).
2. تنظیمات:

   - **Runtime**: Python 3
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `uvicorn main:app --host 0.0.0.0 --port $PORT`
3. (اختیاری) متغیرهای محیطی (جدول پایین).
4. Deploy کنید.

### اجرا روی کامپیوتر خودتان

```bash
pip install -r requirements.txt
uvicorn main:app --reload
# سپس http://localhost:8000
```

## ⚙️ متغیرهای محیطی (همه اختیاری)

| متغیر | کاربرد |
|---|---|
| `ALLOW_SERVER_KEY=1` و `OPENROUTER_API_KEY` | استفاده از کلید سرور وقتی کاربر کلید خودش را وارد نکرده (در این حالت فرانت هم دیگر کلید شخصی نمی‌خواهد). **فقط `OPENROUTER_API_KEY` به‌تنهایی کاری نمی‌کند.** روی سایت عمومی روشن نکنید، چون هر کسی از اعتبار شما خرج می‌کند. |
| `ENABLE_RUN_PYTHON=1` | اجرای کد پایتون روی سرور. سقف زمان (۱۵ ثانیه)، CPU، حافظه و حجم فایل دارد و متغیرهای محیطی سرور به کد داده نمی‌شود، **ولی sandbox واقعی نیست** (شبکه و خواندن فایل‌ها بسته نمی‌شود)؛ فقط برای استفاده شخصی/محلی. برای نمودار، Build Command را به `pip install -r requirements-python-run.txt` تغییر دهید. |
| `RATE_LIMIT_PER_MIN` | سقف درخواست هر آی‌پی در دقیقه برای مسیرهای عمومی (پیش‌فرض ۳۰؛ چت ۲ برابر، PDF نصف، اجرای کد حدود یک‌سوم). `0` = خاموش. |
| `TRUSTED_PROXY_HOPS` | تعداد پراکسی‌های مورد اعتماد جلوی برنامه برای تشخیص آی‌پی از `X-Forwarded-For` (پیش‌فرض ۱). اگر پشت چند لایه پراکسی/CDN هستید و محدودیت نرخ همه را یک نفر حساب می‌کند، این عدد را زیاد کنید. |
| `ALLOWED_ORIGINS` | فهرست مبداهای مجاز CORS، با کاما جدا شده. فقط اگر فرانت روی دامنه دیگری است. |

## 🔑 نحوه استفاده

1. سایت را باز کنید.
2. روی **تنظیمات** (آیکون لغزنده) کلیک کنید و کلید API خود را (از [OpenRouter](https://openrouter.ai/keys)، شروع با `sk-or-v1-`) وارد و ذخیره کنید. کلید دوم اختیاری است و وقتی کلید اول خطای اعتبار یا سهمیه بدهد جایگزین می‌شود.
3. از دکمهٔ **MODEL** یک مدل انتخاب کنید و شروع کنید. امکانات بیشتر (مقایسه، حالت عامل، فروشگاه، داشبورد و …) پشت دکمهٔ **⋯** هستند.

## 🛡️ امنیت (خلاصه)

- خواندن سایت‌ها (`/fetch-url`، ابزار عامل و ابزار «دریافت محتوای وب») فقط آدرس‌های عمومی را می‌پذیرد؛ نام میزبان یک‌بار به IP تبدیل و بررسی می‌شود و اتصال به همان IP انجام می‌شود (ضد DNS rebinding). ریدایرکت‌ها هم یک‌به‌یک بررسی می‌شوند.
- محتوای سایت‌ها در پیام کاربر (داخل بلاک مشخص و به‌عنوان «فقط داده») به مدل می‌رسد، نه در system prompt.
- همهٔ مسیرهای API محدودیت نرخ و سقف حجم درخواست دارند.
- کلید API فقط در مرورگر شما نگه‌داری می‌شود و برای هر درخواست از طریق سرور به OpenRouter می‌رسد.

## ⚠️ نکته‌ها

- پلاگین «جستجوی وب» OpenRouter ممکن است از اعتبار حساب شما کم کند، حتی با مدل رایگان.
- مدل‌هایی که در فهرست با 👁 مشخص شده‌اند تصویر را می‌فهمند.

## 🗂️ ساختار

```

api_routes.py    مسیرهای API (چت، مدل‌ها، PDF، خواندن وب، اجرای کد)
security.py      محدودیت نرخ، سقف حجم درخواست، هدرهای امنیتی
index.html       صفحه اصلی
css/             استایل‌ها (style.css = تم اصلی، extra.css = موارد افزوده)
js/              ماژول‌های فرانت (main, ui, state, api, audio, config)
sw.js            Service Worker (کار آفلاین)
tests/           تست‌ها
```
