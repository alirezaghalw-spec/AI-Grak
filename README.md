# هوش پرو (Hoosh Pro)

دستیار هوش مصنوعی شخصی و چندمنظوره با اتصال به **OpenRouter** (دسترسی به ده‌ها مدل رایگان و ارزان). مجوز: MIT.

## 🌟 ویژگی‌ها

- **چند مدلی:** فهرست مدل‌ها زنده از OpenRouter گرفته می‌شود، جستجو دارد و مدل‌های منقضی خودکار حذف می‌شوند. اگر مدلی در دسترس نباشد، به مسیریاب رایگان برمی‌گردد.
- **رابط مدرن:** راست‌به‌چپ، حالت شب، قابل نصب به‌صورت PWA.
- **پیوست:** تصویر (فشرده‌سازی خودکار، فقط با آخرین پیام ارسال می‌شود)، PDF و فایل‌های متنی.
- **حالت عامل (🤖):** مدل می‌تواند صفحات وب را بخواند (و در صورت فعال بودن، کد پایتون اجرا کند) و با نتیجه ادامه دهد (حداکثر ۴ مرحله).
- **تولید تصویر:** با Pollinations (پرامپت انگلیسی، لینک خودکار اصلاح می‌شود).
- **مکالمه صوتی:** تبدیل گفتار به نوشتار و خواندن پاسخ‌ها. فارسی به صدای نصب‌شده روی دستگاه بستگی دارد.
- **آفلاین:** بعد از اولین بارگذاری موفق، برنامه و کتابخانه‌هایش کش می‌شوند و گفتگوهای قبلی بدون اینترنت قابل مشاهده‌اند (ارسال پیام نیاز به اینترنت دارد).
- **ذخیره محلی:** تاریخچه فقط در مرورگر شما نگه داشته می‌شود.

## 🚀 نصب روی Render

1. مخزن را به Render وصل کنید (New → Web Service).
2. تنظیمات:
   - **Runtime**: Python 3
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `uvicorn main:app --host 0.0.0.0 --port $PORT`
3. (اختیاری) متغیرهای محیطی (جدول پایین).
4. Deploy کنید.

## ⚙️ متغیرهای محیطی (همه اختیاری)

| متغیر | کاربرد |
|---|---|
| `ALLOW_SERVER_KEY=1` و `OPENROUTER_API_KEY` | استفاده از کلید سرور وقتی کاربر کلید خودش را وارد نکرده. **فقط `OPENROUTER_API_KEY` به‌تنهایی کاری نمی‌کند.** روی سایت عمومی روشن نکنید، چون هر کسی از اعتبار شما خرج می‌کند. |
| `ENABLE_RUN_PYTHON=1` | اجرای کد پایتون روی سرور. **sandbox واقعی ندارد؛ فقط برای استفاده شخصی/محلی.** برای نمودار، Build Command را به `pip install -r requirements-python-run.txt` تغییر دهید. |
| `ALLOWED_ORIGINS` | فهرست مبداهای مجاز CORS، با کاما جدا شده. فقط اگر فرانت روی دامنه دیگری است. |

## 🔑 نحوه استفاده

1. سایت را باز کنید.
2. روی **⚙** کلیک کنید و کلید API خود را (از [OpenRouter](https://openrouter.ai/keys)، شروع با `sk-or-v1-`) وارد و ذخیره کنید.
3. از منوی **MODEL** یک مدل انتخاب کنید و شروع کنید.

## ⚠️ نکته‌ها

- پلاگین «جستجوی وب» OpenRouter ممکن است از اعتبار حساب شما کم کند، حتی با مدل رایگان.
- مدل‌هایی که در فهرست با 👁 مشخص شده‌اند تصویر را می‌فهمند.
- کلید API فقط در مرورگر شما ذخیره می‌شود و برای هر درخواست از طریق سرور به OpenRouter می‌رسد.
